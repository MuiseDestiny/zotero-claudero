# Claudero

Claudero est une extension Zotero qui intègre Claude Code, Codex et DeepSeek
Harness dans l'espace de travail Zotero. Elle permet de travailler avec les
articles, les PDF, les annotations et les notes de votre bibliothèque.

Cette page est un point d'entrée en français. La documentation complète et
les instructions d'installation sont disponibles dans les README suivants :

- [Documentation en anglais](../README.md)
- [Documentation en chinois simplifié](./README-zhCN.md)

Le code source et les versions publiées sont disponibles sur
[`MuiseDestiny/zotero-claudero`](https://github.com/MuiseDestiny/zotero-claudero).

## Installation rapide

Téléchargez le fichier `.xpi` depuis la page [Releases](https://github.com/MuiseDestiny/zotero-claudero/releases), puis installez-le dans Zotero avec **Outils -> Modules complémentaires -> Installer un module depuis un fichier**.

Installez Node.js 20 ou une version ultérieure, puis configurez le fournisseur
dans les préférences de Claudero. DeepSeek Harness nécessite Node.js 24 ou plus.
